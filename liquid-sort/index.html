Сортировка воды: Яркие Бутылки

Политика конфиденциальности

Эта политика описывает, какие данные используются в игре «Сортировка воды: Яркие Бутылки» для Android и при обращении к разработчику Frozen Pixel.

Данные игры на устройстве

Игра хранит номер открытого уровня, остаток бустеров и настройки музыки и звуков в хранилище приложения на устройстве. Для удаления этих данных очистите хранилище игры в настройках Android или удалите приложение.

Для игры не требуется учётная запись. Игра не отправляет разработчику прогресс, остаток бустеров или настройки. Ссылка на политику в меню открывает эту страницу в браузере.

Реклама с наградой

Для пополнения бустеров в Android-версии можно выбрать просмотр рекламы. Создано с использованием Yandex Mobile Ads SDK. Рекламный сервис может обрабатывать IP-адрес, рекламный идентификатор Android, сведения об устройстве, приложении и взаимодействии с рекламой. Подробнее об обработке данных можно узнать в политике конфиденциальности Яндекса.

Посещение сайта

Страница размещена на GitHub Pages. При открытии страницы GitHub может получать технические сведения о запросе, включая IP-адрес. Подробности приведены в политике конфиденциальности GitHub.

Обращения к разработчику

Если вы пишете нам, мы используем ваш адрес электронной почты и сведения из письма, чтобы ответить и решить описанную проблему. Переписка хранится на время рассмотрения обращения и дольше, если её сохранение требуется по закону или для разрешения спора.

По вопросам обработки, исправления и удаления данных напишите на frozenpixel@mail.ru и укажите название игры.
